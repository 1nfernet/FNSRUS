# Истоки и источники FNSRUS

## Откуда возник проект

FNSRUS появился из практической задачи: развернуть MCP-проверку российских
контрагентов и сделать её удобной в обычном браузере, без LLM-клиента.
Первоначальный встроенный explorer был заменён собственным русскоязычным UI.
Начальный локальный коммит: `924f48c`, 13 октября 2026 года.

Далее добавлены полный просмотр и копирование JSON, настройки API-ФНС,
проверки сохранения секретов и диагностика ограничений поставщиков.
Публичная версия 1.0 подготовлена после подтверждения работы интеграции:
тестовый ключ API-ФНС был привязан к одному IP, и в кабинете разрешили
внешний IP сервера вместо адреса клиентского браузера.

Это самостоятельная обвязка, а не новая реализация государственных реестров
и не форк всего MCP-проекта. Код upstream не встраивается в этот репозиторий:
его пакет запускается отдельно через `uvx`.

## Что разработано в FNSRUS

- `server.py`: HTTP API, MCP stdio-клиент, проверка схем аргументов, лимиты,
  ошибки, изолированный кэш и маршруты настроек.
- `api_fns.py`: запросы API-ФНС, проверка и приватное хранение ключа,
  очистка секретов, объединение карточки и аналитики без потери исходных полей.
- `templates/index.html`, `static/app.js`, `static/style.css`: собственный
  интерфейс на HTML, CSS и JavaScript, навигация, копирование, диалог настроек.
- Тесты, конфигурации systemd/Nginx, CI, документация и release-материалы.

Разработка и проверка выполнялись владельцем проекта с помощью GitHub Copilot
в VS Code. Сторонние компоненты перечислены отдельно; их авторство не
приписывается FNSRUS. Корректность данных определяется источниками, не ассистентом.

## Откуда берутся сведения

Открытые проверки выполняет upstream MCP: ЕГРЮЛ/ЕГРИП, открытые наборы ФНС,
ЕФРСБ, ФССП, КАД и другие предусмотренные им источники. FNSRUS не создаёт
собственную копию этих государственных систем и не обходит CAPTCHA или блокировки.
Реестры массовости и долгов требуют штатной загрузки реальных наборов upstream.

Опциональный [API-ФНС](https://api-fns.ru/) - сторонний сервис ДаМИА,
а не официальный API ФНС. Используются только документированные `stat`, `egr`
и `check`: [описание API](https://api-fns.ru/api_help).
Тариф, лимиты, IP-привязка и права на данные определяются поставщиком.

Бухгалтерская отчётность, PDF-выписки и другие методы не реализованы в 1.0,
даже если они доступны по ключу. Нет заявления о стопроцентном покрытии рисков:
недоступный источник отображается как недоступный, а не как отсутствие нарушений.

## Лицензии и изображения

Собственная обвязка и интерфейс распространяются по MIT (`LICENSE`).
Иконки и шрифты сохраняют свои лицензии и авторство. Код лицензируется отдельно
от сведений поставщиков: MIT не предоставляет права на перепубликацию их баз.

Скриншоты в `docs/screenshots` сняты с работающего FNSRUS. Ключи, пароли,
рабочие базы и полный архив ответа поставщика не входят в релиз. Подробности
проверки и ограничения публикации указаны в `release-1.0.md`.
